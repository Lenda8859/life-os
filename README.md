# Life OS — Моя новая жизнь

Локальное приложение для управления целями, задачами, привычками и основными
сферами жизни. Проект развивается постепенно как полезный инструмент и учебный
проект по Python, SQL и архитектуре приложений.

## Текущий статус

Готова первая итерация: минимальная стартовая страница без базы данных и
пользовательских модулей.

## Технологии

- Python 3.12+
- Streamlit
- pytest
- Ruff

SQLAlchemy, SQLite, pandas и Plotly будут подключаться на соответствующих этапах.

## Установка

На Windows:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements-dev.txt
```

## Запуск

```powershell
streamlit run app.py
```

После запуска откройте адрес, показанный Streamlit, обычно
`http://localhost:8501`.

## Тестирование и проверка кода

```powershell
pytest
ruff check .
```

## Структура первой итерации

```text
app.py                 точка запуска
life_os/config.py      название и описание приложения
life_os/pages/         страницы интерфейса
life_os/assets/        визуальные стили
tests/                 автоматические тесты
docs/                  архитектура и журнал разработки
data/                  место будущей локальной базы
```
