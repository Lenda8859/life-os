# Архитектура Life OS

Life OS развивается небольшими проверяемыми итерациями.

Планируемое направление зависимостей:

```text
Streamlit pages → services → SQLAlchemy → SQLite
```

Интерфейс не должен содержать SQL и бизнес-расчёты. В первой итерации создана
только стартовая страница без базы данных.
