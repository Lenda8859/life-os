# Архитектура Life OS

Life OS развивается небольшими проверяемыми итерациями.

Направление зависимостей:

```text
Streamlit pages → services → SQLAlchemy → SQLite
```

Интерфейс не должен содержать SQL и бизнес-расчёты.

## Реализованные слои

- `app.py` — точка сборки интерфейса;
- `life_os/navigation.py` — выбор страниц;
- `life_os/pages/` — отображение данных;
- `life_os/database/models.py` — описание таблиц;
- `life_os/database/connection.py` — engine, сессии и транзакции;
- `migrations/` — воспроизводимая история схемы;
- `data/life_os.db` — локальные пользовательские данные, исключённые из Git.

Сервисный слой будет добавляться вместе с CRUD жизненных сфер и целей.

## Управление базой

Пользовательская база создаётся только явной командой:

```powershell
python -m life_os.database.init_db
```

Команда применяет все Alembic-миграции до `head`. Импорт приложения сам по себе
не создаёт таблицы и не меняет данные.

Тесты передают отдельный URL базы, расположенной во временной папке pytest.
Поэтому они не открывают и не изменяют `data/life_os.db`.
